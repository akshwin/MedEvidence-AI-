IMPORTANT NOTES
================================================================================

1. SECRET_KEY: I've generated a secure random key for you. Keep this secret!

2. FRONTEND_URL: You MUST update this after deploying your frontend to Vercel.
   - Deploy frontend first
   - Get the Vercel URL (e.g., https://medevidence-ai.vercel.app)
   - Come back to Render → Environment → Update FRONTEND_URL
   - Save changes (Render will auto-redeploy)

3. DATABASE_URL: Starting with SQLite for simplicity. For production:
   - Create PostgreSQL database on Render (free tier available)
   - Update this variable with the PostgreSQL connection string

4. SMTP Settings: Already configured with your Gmail. Make sure:
   - You're using an App Password (not your regular Gmail password)
   - 2-factor authentication is enabled on your Gmail account

5. API Keys: These are your actual keys from your .env files. Keep them secure!

================================================================================
HOW TO ADD THESE IN RENDER
================================================================================

1. Go to Render Dashboard → Your Backend Service
2. Click "Environment" in the left sidebar
3. For each variable:
   - Click "Add Environment Variable"
   - Enter the KEY (e.g., GROQ_API_KEY)
   - Enter the VALUE (your actual secret value)
   - Click "Save"
4. After adding all variables, click "Save Changes"
5. Render will automatically redeploy your service

OR use the "Add from .env" option:
1. Click "Add from .env"
2. Paste the entire "COPY-PASTE FORMAT" section above
3. Click "Add Variables"
